🚦 Vocabulary Pilot Release Gate

A conservative gate for deciding whether the current pilot build is ready for another controlled release.

Decision

Release Principles

🛑 Blockers first
Any unresolved blocker keeps the build out of the next pilot release.
🔁 Retest before release
A fix must be retested through the affected student flow before it counts as verified.
📋 Evidence over assumptions
Use observations and structured feedback; do not treat local prototype metrics as statistically representative.
🎓 No unsupported efficacy claims
Pilot readiness is a product-quality decision, not evidence that the system improves CEFR proficiency.
