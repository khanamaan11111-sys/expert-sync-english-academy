🧪 Vocabulary Pilot Center

A controlled pilot workflow for testing the vocabulary system with real students before wider rollout.

Pilot Workflow

1. Student Onboarding
Give the student the onboarding flow and explain that this is a pilot.
2. Baseline Vocabulary Activity
Ask the student to search words and complete one normal learning session.
3. Active Practice
Use Context Mastery, Sentence Builder and Pronunciation Lab.
4. Review & Retention
Return through Smart Review and Spaced Repetition.
5. Student Feedback
Complete the structured feedback form after using the system.

📋 Pilot Checklist

🎯 Recommended Pilot Session

Keep the first pilot focused. Ask students to complete one onboarding flow, learn 5–10 words, do one context activity, create sentences, practice pronunciation, review vocabulary and then submit feedback. Record qualitative comments separately if you need detailed interviews.
